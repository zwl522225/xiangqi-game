# 学习备份文件

在「新手课堂 → 学习总览 → 备份与恢复」下载或选择学习备份。文件由用户手动保管和转移，无需账号、不上传、不自动同步。下载提示表示浏览器已接到下载请求，实际文件请在浏览器下载列表查看。

## 内容与替换范围

至少选择一个可备份模块。未选择的模块在 `modules` 中完全省略，不写入 `null` 或默认记录。

| 键 | 界面名称 | 内容 |
| --- | --- | --- |
| `coursePractice` | 课堂与单步练习 | 旧章节、旧残局、知识点已练与掌握、受提示变式、首盘里程碑、单步记录及当前轮 |
| `opening` | 开局跟练 | 八组跟练历史及当前轮的实际进度、错误和帮助记录 |
| `tactics` | 多步战术 | 六题历史、待复习、最近错误及当前轮，包括实际路径与示范答案后缀 |
| `endgame` | 残局分步教学 | 六题历史及最多一个当前轮，包括路线前缀、错误与辅助记录 |

不包含正式对局 `session`、当前实战教练 `learningMatch`、收藏、棋谱笔记、试走草稿、显示偏好或临时课堂局面。用于终局恢复核对的本机元数据 `restoredTerminalMatch` 也不进入备份。迁移棋局请使用原有棋局文件功能。源项目的 MIT 许可保持不变。

棋谱识读专项复用 `coursePractice` 的 `practicedUnits`、`masteredUnits` 和 `assistedVariants`，不增加第五个模块、字段或格式版本。四个新知识点 ID 为 `notation-files`、`notation-straight`、`notation-target-file`、`notation-front-back`，各有三个变式；展开变式路数辅助的受助证据会备份，临时棋盘、本题视角和辅助表展开状态不会备份。

当前应用可读取第 15 版及更早的有效旧课堂存档和旧 v1/v2 学习备份，保留原 17 项 ID 及其他记录；缺少新四项记录表示暂无记录，不自动补造已练或掌握。含新 ID 的文件可在当前应用往返，但旧版本应用可能因其既有严格目录而拒绝，即使文件仍为 v1/v2 也不保证任意版本双向兼容。未知 ID、已掌握却未练习等无效内容会整份拒绝，不会静默删去。

仅成功恢复且记录有变化的课堂与单步模块会重新初始化课堂题面；恢复其他三个模块、取消、同值恢复或恢复失败均保留当前课堂题面。切换总览/备份再返回也保留当前题的视角、辅助展开和提示。

## 格式与限制

UTF-8 JSON 文件以 `yixiang-learning-backup-YYYYMMDD-HHmmss.json` 命名。`exportedAt` 是带毫秒与 `Z` 的有效 UTC ISO 时间，仅用于显示。以下是合法的仅课堂与单步练习空记录示例：

```json
{
  "format": "yixiang-learning-backup",
  "version": 1,
  "exportedAt": "2026-10-22T01:02:03.000Z",
  "modules": {
    "coursePractice": {
      "completedLessons": [],
      "solvedPuzzles": [],
      "practicedUnits": [],
      "masteredUnits": [],
      "assistedVariants": [],
      "milestones": { "firstMatch": false, "independentMatch": false },
      "practice": { "version": 1, "records": {}, "round": null }
    }
  }
}
```

版本 1 只接受原有 `coursePractice`、`opening`、`tactics` 三个模块，继续支持旧文件；在版本 1 中加入 `endgame` 会拒绝。版本 2 接受上述四个已知模块的任意非空组合，不要求包含 `endgame`。导出选择包含残局分步教学时写版本 2，否则继续写版本 1。恢复旧文件只替换所含模块，不会清空或写入残局分步教学。

整个文件最多 256 KiB（包含 JSON 字段、缩进等开销）；课堂与单步块最多 128 KiB、开局块最多 32 KiB、战术块最多 64 KiB、残局分步教学块最多 32 KiB。各块分别合格但整体超限也会拒绝，不会静默删块。读取前检查文件大小，读取后重新检查 UTF-8 字节数。未知格式、版本、字段、模块、内容 ID、重复 ID、不相容状态和缺乏规则证据的记录均会拒绝。任一模块错误会使整个文件无法进入恢复预览。棋局 JSON 与学习备份不可互换。

文件只支持当前内容目录与训练题版本，不能承诺未来目录变化后的兼容性。已掌握知识点必须已有练习记录，独立首盘必须已有首盘记录；辅助结果、错误、揭晓和跳过保留原意。学习记录是个人快照，不是成绩认证，也不因导入而产生额外奖励。

## 当前页面记录、失败与保护

导出使用点击下载时的当前页面数据。能严格校验的未保存记录可以导出，并提示“包含尚未写入本机的记录”；不会用旧磁盘记录替代它。开局、战术或残局分步教学存档受保护时，该模块不可导出，临时练习也不会被当作完整历史。课堂与单步的原学习或棋局存档无法读取时，该模块不可导出或恢复，需先处理原存档问题。

选文件、预览、取消和返回总览均不写学习存储。预览显示文件名、导出时间、所含模块以及当前与备份摘要；文件名仅作文本。更新文件、取消或离开面板会使尚未完成的旧读取结果失效。

每次恢复一个模块，先展示替换范围再确认，没有全部恢复按钮。恢复替换该模块的完整快照和当前训练轮，不合并、不自动走应手、不自动进入下一题。恢复开局、战术或残局分步教学受保护存档时，确认会明确说明“将以备份替换本模块受保护存档”。

写入现有存储键成功后才更新当前页面。失败保留原存档和内存，预览可以重试；相同记录提示“与当前记录一致”，不写入，也不清除原有未保存提示。残局分步教学的受保护临时默认记录不参与相同判断，确认替换后必须实际写入成功才能解除保护。每个模块结果分别显示，成功项在本次预览中停用。四个模块分别写入，不具有跨键事务保证。

成功改变课堂与单步记录后回到学习总览，并重新初始化课堂实例；当前临时题面不属于恢复内容。浏览、导出、预览、取消、仅恢复开局、战术或残局分步教学时保留当前课堂题面、提示和已见变式。其他模块、正式棋局、收藏和偏好保持原记录。刷新后可继续所恢复的训练快照；清除网站数据仍会删除本机存档。

残局分步教学恢复保留备份中的路线节点与辅助证据，不自动走应手、不增加奖励。完成记录与本轮无提示且无错误记录分别保存；后者不代表此前未见题目，也不代表残局掌握认证。
