# 弈象 · 中国象棋入门

面向新手的中国象棋网页游戏。打开后即可在棋盘上走棋，也可切换到教学、棋路、术语或残局练习。

## 本机运行

需要 Node.js 20.19+ 或 22.12+。在本目录运行：

```sh
npm ci
npm run dev
```

打开终端给出的本地地址。生产构建使用 `npm run build`，本机预览使用 `npm run preview`。`npm test` 运行规则、内容、存档和界面测试；`npm run typecheck` 检查类型。

## 内容与操作

- **开始对弈**：本机双人或人机练习；支持合法落点提示、棋谱回看、悔棋、认输。本机双人可提和与接受提和。
- **棋盘视角**：人机默认跟随执棋方，执黑时黑方在下；可手动翻转或恢复跟随。方向键按屏幕方向移动，棋谱坐标仍是真实坐标。一般教学与规则示例固定红方在下，开局跟练按本组执棋方显示。
- **棋盘显示**：页头可选择传统木纹或清晰教学主题、显示数字坐标，以及显示或隐藏本局失子。主题与坐标用于全站棋盘和紧凑示例；默认木纹、关闭坐标、开启失子列表。数字坐标为 `(x,y)`：横向 0 至 8、纵向 0 至 9，与棋谱数字坐标和棋局文件一致，与中文记谱中的一至九路不同；翻转时数字随格点对应变化。
- **本局失子**：对弈与收藏预览分别显示“红方已失”“黑方已失”，依据真实规则和前后局面统计，不用棋盘缺子推算。列表跟随回看、回放、悔棋和刷新，仅统计本局棋谱中的吃子，不包含棋路起始前缀；无法核对的历史会明确提示。静态教学图不推断此前吃子。
- **电脑难度**：启蒙比较本着，入门考虑对方下一着，挑战尝试再考虑自己的回应。搜索最多看一、二、三着，受候选数与 2000 节点预算限制，不代表棋力等级分；计算异常或超时会采用合法基础策略并提示。视角与难度独立保存，刷新和新局保留。
- **学习复盘**：通过首末按钮、逐着按钮或键盘进度条回看；结束局可自动回放与暂停。每着说明按规则引擎重放核对移动、实际吃子、将军及规则终局。每着可明确保存或清除最多 500 字笔记；刷新恢复，悔棋删除撤回着法的笔记，新局清空。写笔记与回看不会改变胜负或学习记录。
- **棋局收藏**：最多保存 20 盘完整棋局及已保存笔记，可重命名、独立只读回看、删除或清空。收藏不受当前回看位置影响，也不会随正在进行的对局改变。非终局可明确选择本机双人或人机及执棋方，从末着复制出新的练习局；续练可以使用教练，但不授予首盘或独立首盘记录。
- **棋局文件**：当前局或收藏可导出弈象 JSON，默认不含笔记，主动勾选后才带出已保存笔记。选择文件后先逐着校验和预览，再加入为新的收藏；预览和取消不改当前局。支持标准开局和可验证的棋路前缀，每盘合计最多 600 着，单文件最多 512 KiB。格式与示例见 [棋局文件说明](docs/game-file-format.md)。
- **复盘试走**：在对弈或收藏／导入预览中选择回看位置，点击“从此处试走”，独立尝试一条变化。双方均由自己走棋，支持悔棋、回看、逐着说明、保存笔记，以及确认后从所看位置改走；起点之前的吃子不计入试走失子。可另存为收藏或导出原格式 JSON，原对局和源收藏保持独立，试走不授予学习奖励。
- **新手课堂**：八章、17 个知识点，每个知识点按“看示范 → 自己练 → 换题挑战”学习；每题有分层提示和答案解释。看过提示的题可反复练习，通过另一道未受提示的变式才记为“已掌握”。旧版章节完成记录保留，不直接折算为掌握。
- **学习总览**：在「新手课堂 → 学习总览」查看课堂、单步练习、多步战术、开局跟练、旧残局和首盘记录。集中列出尚未结束的训练轮和待复习错题，并说明下一步建议的依据；入口只前往原页面，由自己选择继续或开始，不会自动替换轮次。
- **主题练习**：基础走法、吃子与保护、将军与应将、终局判断、记谱与开局五个主题，各有四道独立题。可按主题练习，或开始最多五题的推荐轮次；推荐优先安排待复习错题及已练未掌握的相关知识点。支持三层提示、揭晓、重试、跳过和刷新续练，小结区分首次无提示完成、提示或重试后完成、跳过；刷新后仍可查看上轮小结。
- **错题再练**：实际走错或选错才记入错题；合法但未达目标与规则不允许的走法分别说明。另开一轮首次无提示答对后移出待复习，以后再错会重新加入。同轮改正或看提示后完成仍待复习。练习不改变课堂掌握、提示记录、正式棋局或首盘里程碑；可单独清空练习记录。
- **多步战术**：在「主题练习 → 多步战术」进入六道原创题，连续将军、吃子获利、解将反击各两题，执红执黑各半。自己走两至三步，对方点击后走指定应手；全部正确解和合法防守经有限目标验证，合法但未达本题目标的走法会另行解释。三层提示、示范本步、反例与完整变化可主动查看；按主题每轮两题，推荐和战术错题每轮最多三题。
- **战术小结与回看**：区分本轮首次无提示且无错误完成、辅助完成、已看答案和跳过。保留实际正确前缀，完整答案的示范后缀单独标记；局部逐着回看跟随真实吃子、将军与终局，最近错误使用当时的独立局面重放。查看答案后重新挑战仍保留辅助历史；另一轮独立答对才移出待复习战术错题。
- **第一盘实战**：第八章可选择带提示或独立下棋。实战教练提供观察顺序，可随时关闭；十个完整回合后显示一次提醒。终局小结说明实际结果、双方着数和回合数，并可回看棋谱、直接复习本局相关知识点。标准开局的人机对局以将死、困毙或自然限着结束才记录首盘；全程未开启教练、玩家自行走棋另记独立首盘。操作工具代走可完成首盘，但不能记为独立首盘；认输与议和不授予这两项记录。
- **棋路馆**：四条各八着的原创入门路线，可逐着观看，亦可从展示的局面继续练习。路线展示一种教学思路，不代表唯一或最佳走法。
- **开局跟练**：四条路线分别练习执红和执黑，共八组，每组自己走四步。对方按指定示例应手，点击后再走一着并说明用意；支持三层提示、示范本步、错误重试与本轮小结。非法着法与合法偏离分别反馈；合法但不在路线中的着法不因此判为坏棋。
- **术语词典**：可搜索的 31 个常用术语和示例局面。
- **残局练习**：六个入门题，走出目标着法后记录完成进度。
- **规则手册**：棋子走法、终局、和棋、记谱与循环棋例的简要说明。

棋盘支持鼠标和触摸操作。键盘先将焦点移入棋盘，再用方向键移动焦点、Enter 或空格选子与落子，Escape 取消选中。对局与学习进度保存在当前浏览器的本机存储中。

刷新可恢复棋局、学习进度和本局提示历史；关闭教练或悔棋不会清除曾使用提示或工具代走的记录。电脑和平板可以通过网站游玩，横屏宽度足够时棋盘与资料并排，窄屏按上下顺序展示。本机存档不会自动同步到另一台设备或另一个浏览器；清除网站数据会删除存档。

笔记先编辑草稿，再点击“保存笔记”。浏览器写入失败时，复盘面板会提示当前内容仅留在页面，刷新后可能丢失；未保存的草稿不承诺恢复。旧版无笔记存档仍能读取。

显示偏好与棋局进度独立保存在当前浏览器中，不随棋局 JSON 转移。设置面板显示实际保存状态；保存失败时当前页面仍保留选择，刷新后可能丢失。切换显示不会重新开局或改变学习记录。

收藏的规范化 JSON 总量最多 2 MiB；达到容量上限时需先删除或导出，不会自动清理旧棋局。收藏页显示实际保存状态，浏览器存储不足时内容可能只留在当前页面。可通过下载和导入文件在设备之间手动转移棋局；本机收藏不自动同步，清除网站数据会删除它们。

“试走研究”最多独立保存一个草稿，刷新后可从该入口恢复回看位置、朝向和已保存笔记。新建另一条试走前会确认替换；进入研究会停止原对局的电脑请求和来源自动回放，返回对弈后按原规则继续。草稿使用紧凑着法保存，不包含原局后续或未保存笔记；单份最多 512 KiB，保存失败时页面会提示，当前内容仍可继续研究，但刷新可能丢失。

开局跟练独立保存八组完成记录和一组当前轮次，刷新后在棋路馆的跟练入口继续。提示、示范和错误记录随当前轮保留；只有本轮全程未用提示或示范、且没有走错时，才记为无提示且无错误完成。这只描述短路线的本轮表现，不等于掌握整个开局。跟练不改变正式棋局、课堂、主题练习、收藏、复盘草稿或首盘奖励。重练或替换未完成轮前会确认；本项记录最多 32 KiB，写入失败会提示未保存并可重试，损坏记录需要主动重置后才能覆盖。

多步战术独立保存六题历史与最多一轮三题，容量上限 64 KiB。刷新后主动进入该入口继续；错误、提示、示范和重试历史保留。读写失败会明确提示，页面内存仍可练习；损坏原值保留，主动重置成功后才能覆盖。重置仅清除本项，训练不写正式棋局、课堂、单步练习、开局跟练、收藏、试走草稿或奖励。战术完成标记只描述这些短题的经历。

学习总览只读取当前页面已有记录，不新增存档或奖励。课堂掌握、短题曾完成和本轮表现分别统计；单步练习的提交次数不当作成功次数。无法恢复的开局或战术历史明确显示未知，临时练习和保存失败也有说明。在当前课堂内切换总览会保留题目、阶段、提示和本次访问已见的变式；离开课堂或刷新后，课堂仍按原有知识点入口进入，不承诺恢复课堂棋盘。

战术中的净吃子记分只统计题目起点后的实际吃子：车 9、马与炮 4、仕士与相象 2、兵卒 1。获利目标包含最后一次防守，反击目标也检查对方应将后的结果；这些有限步数目标不代表长期胜负或引擎评分。开发侧题目编译与独立检验位于 `tests/helpers/tactics-compiler.ts` 和 `tactics-reference.ts`，内容验证运行 `npm test -- tests/tactics-content.test.ts tests/tactics-goals.test.ts`；浏览器只重放规则并读取已验证变化。

试走的起始前缀与新增着法合计最多 600 着，达到上限可回看、悔棋、收藏或导出；此限制只用于试走与文件兼容，正式对局和长棋谱回看仍按原规则运行。至少新增一着后才能收藏或导出试走；未结束的所选起点才能开始研究，已结束局面可回到更早位置。

## 规则来源与边界

基本走法和终局依据中国象棋协会审定的[《象棋竞赛规则（2020版）》](https://cnchess.net/rules/rules2020.html)。本游戏执行红先、双方轮流行棋、合法走法、禁帅将照面、禁送将、将死、困毙及 60 回合无吃子自然限着。重复局面会提示；长将、长杀、长捉等复杂循环需要依据具体棋例裁决，游戏不会自动给出赛事级判决。电脑棋手只用于入门练习。

## 项目结构

`src/core/` 是纯函数规则与对局状态，`src/content/` 是教学内容，`src/ai/` 是电脑棋手，`src/ui/` 是界面。无后端和账号，所有存档只在当前浏览器设备内。
